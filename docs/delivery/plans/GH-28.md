## Design

Retain native anchors, adding an addressable Inicio hero. Public section links receive explicit destination metadata. A browser-local geometry selector chooses the section crossing the center of the unobscured viewport, with the last section selected at document bottom so short contact sections remain reachable. An explicit link/history destination remains current while visible; subsequent scroll movement or wheel/touch/scroll-key intent resumes geometry selection. One scheduled scroll update sets exactly one aria-current=location indicator; its existing bold/heavy underline preserves the visual system. No unconditional public Inicio current marker appears in static markup.

Native link activation creates history entries and focuses the target without an extra scroll. Passive scrolling replaces only the current entry's section hash, preserving query/path and previous link entries; direct hash entry, hashchange/popstate and browser restoration re-evaluate actual geometry. Measure header height and observe content resize to handle wrapping and async public content without fixed section heights. Keep the existing compact menu/keyboard/Escape behaviour. No SDK, listener or private request is added.

The selector is a small pure seam for boundary/bottom tests; actual browser/history/focus evidence is decisive. No UI framework, router, new tokens, editorial data, access/rules change or ADR is needed. Runtime quality realization updates arc42 05/06/10 and design patterns, citing accepted artifacts with CLI payloads. Existing public/private projections remain unchanged.
