# Introduction and Goals

## Requirements Overview

[The accepted ProductShape baseline](../product/model/) owns product intent; [CHG-INITIAL](../product/changes/completed/chg-initial/change.md) records its application. GH-1 established the executable shell; GH-2–GH-9 delivered gated musical workflows and public discovery, with presentation refined by GH-20–GH-22. [The delivery map](../delivery/README.md) distinguishes that current realization from the navigation extension defined by [CHG-AREA-NAVIGATION](../product/changes/completed/chg-area-navigation/change.md), whose application implementation belongs to GH-28–GH-30.

## Quality Goals

[Section 10](10-quality-requirements.md) maps governing quality artifacts to mechanisms and evidence. The existing application combines static public delivery, canonical token reuse and browser-only, rules-enforced private workflows. Navigation realization gaps are explicit in section 10.

## Stakeholders

Juan owns product and delivery acceptance. Humans and agents use the [engineering lifecycle](../engineering-lifecycle.md), accepted ProductShape artifacts and architecture evidence together.
